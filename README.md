# AkshathaaRk.github.io

Personal portfolio of **Akshatha RK** — AI/ML Engineer based in Bangalore.

Building agentic AI systems, RAG pipelines, and LLM-powered applications.

## Live site

https://akshatharkk.github.io

## Stack

- **Framework:** Next.js 14 (App Router, static export)
- **Styling:** Tailwind CSS
- **Type:** TypeScript
- **Animation:** Framer Motion
- **Typography:** Fraunces (serif), Ubuntu (body), JetBrains Mono (mono)

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

The static site is generated into `out/`.

## Deploy

Every push to `main` triggers `.github/workflows/deploy.yml`, which builds the
static site and publishes it to GitHub Pages.
